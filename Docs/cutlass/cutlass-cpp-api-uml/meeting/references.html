同步接口之外还要查什么

Allocator2Sm::release_allocation_lock() 只是放弃分配许可，不是释放已分配的 TMEM。其声明见 固定源码第 174 行。Kernel 在调用 free() 前的独立等待、双 CTA 握手与条件分支见 第 783 行起 和 TMEM 协议详细图。

cudaStreamSynchronize(stream) 是本参考应用的显式等待，不在 Adapter 内部。见 已保存的示例调用位置。其他实现应说明自己的等价完成条件；不能只检查执行接口的返回值。

本包引用已发布的静态编译材料，但没有新增 GPU 执行。完整 Copy 分派、全部描述符/调度/融合行为和其他配置尚不能由这些接口证明。未展开事项在会议记录中另立问题，不由简图补猜。
