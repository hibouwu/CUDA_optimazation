# L1：CTA / SM 片上计算能力

[层级总览](../README.md#模型层级) · [统一接口](interfaces.md)

## 系统边界

输入块在 SMEM 就绪，输出结果在约定的片上位置就绪。分别建立单 CTA 执行模型和单 SM 上驻留 CTA 的并发模型；同时说明输入缓冲和累加存储何时可以复用。

服务单位由工作块内的线程/数据映射、片上取数与计算需求定义，可以接收给定就绪时刻的一串工作块。本层不自行安排 GMEM 预取、环形输入缓冲或完整 K 主循环；这些组织由 L2 的方案实例给出。理想供给下的片上能力与给定到达序列下的完成时间分别报告。

## 建模接口

- 输入：工作块形状、计算需求与供给序列、各块输入就绪时刻、初始累加状态、线程组织、片上布局、结果位置、缓冲与同步方式、资源分配量、驻留配置，以及 [L0](L0.md) 的服务参数。
- 输出：累加结果就绪时刻、各输入缓冲及累加缓冲的可复用时刻、单 CTA 完成时间、指定驻留条件下的单 SM 吞吐量；单 CTA 吞吐量不能直接乘以驻留数当作 SM 吞吐量。

缓冲可复用时刻由实际消费者完成事件确定，不能用异步指令发出时刻替代。[L2](L2.md) 的协作流水线根据搬运完成事件提供输入，并接收缓冲释放事件；[L3](L3.md) 统一处理全 GPU 的任务分配与共享服务竞争。具体事件图由后续方案模型给出。

## 资源与需求

### 计算资源引用

计算、搬运、同步和辅助操作引用 [L0](L0.md)。本层描述一个 CTA 及同一 SM 上各驻留 CTA 对这些服务的使用，不新增一份计算吞吐上限。

### 存储与缓存容量

| 占用对象 | 需要给定的量 | 约束 |
|---|---|---|
| 寄存器操作数、累加器和控制状态 | 实际分配量、分配粒度与生存期 | 每线程、CTA 和 SM 限制，以及驻留时的同时占用 |
| SMEM 输入、输出与同步状态 | 对齐后大小、缓冲槽数、持有与释放时刻 | 每 CTA 分配上限、每 SM 容量和缓存 carveout |
| 专用累加存储（仅目标支持时） | 该存储的分配单位、范围和释放条件 | 按目标架构自身规则约束，不能从单次分配上限推出多 CTA 总容量 |

容量条件统一采用 [对象占用区间](interfaces.md#3-共享资源)。具体数值和分配规则见 [Thor L1](../hardware/thor_sm110/L1.md) 或 [GH200 L1](../hardware/gh200_sm90/L1.md)。各资源上限不保证能同时达到。

### 带宽与数据搬运

| 片上路径 | 需要给定的需求 | 服务条件 |
|---|---|---|
| SMEM ↔ 寄存器 | load/store 数量、宽度、线程地址与布局 | 广播、bank conflict、发射与数据通路限制 |
| 计算指令的操作数供给 | 引用 [L0 数据供给需求](L0.md#数据供给需求) | 保留计算服务已包含的部分，只补充边界之外的访问或竞争 |
| 专用累加存储读回（若支持） | 读取形状、参与者和结果位置 | 所选指令的完成与共享条件 |

线程 SMEM load/store、计算指令取数和搬运写入 SMEM 的服务不能互相替代。结果写入 SMEM 仅在输出接口要求时计入。

### 驻留与指令发射

驻留配置同时满足线程、warp、CTA、寄存器、SMEM 及所选专用资源的约束。同一 SM 上多个 CTA 的执行须共享发射与访问能力，不能把单 CTA 吞吐量直接乘以驻留数。

| 发射或执行资源 | 本层需求 | 需要确定的服务参数 |
|---|---|---|
| warp 调度与指令发射 | 各 warp 的可发射指令及依赖 | 发射能力、并发时的竞争；L0 已计入的部分不重复相加 |
| 访存指令执行 | SMEM load/store 等指令 | 指令发射能力与数据带宽分别描述 |
| 辅助指令执行 | 地址计算、循环控制、类型转换与结果处理 | 按所选方案记录需求及与计算指令的共享关系 |

### 同步约束

| 同步机制 | 关联对象 | 本层约束 |
|---|---|---|
| CTA barrier | 参与同步的线程 | 到达条件与等待时间 |
| `mbarrier` / 异步完成通知 | 输入缓冲、搬运与消费者 | 使用输入前等待搬运完成；复用缓冲前等待消费者完成 |
| 异步计算完成等待 | 累加状态与计算结果 | 引用 L0 完成事件，确定读回和存储复用时刻 |

软件缓冲及同步状态占用上述存储资源，不单独增加容量。TMA 的操作与完成接口见 [L0](L0.md#数据搬运操作)，全局路径需求见 [L2](L2.md#带宽与数据搬运)；L2 按流水线安排请求，本层描述片上分配、输入就绪和缓冲可复用条件。

## 时间模型

工作块的操作需求和事件遵循[统一接口](interfaces.md)。已给出 [FP32 SIMT 的分阶段推导](../schemes/fp32_simt_tiled.md#3-l0-到-l1一个-k-分块的片上时间)作为有限执行组织的示例；通用交错与竞争模型仍需继续推导。

待推导：片上取数、计算、结果处理之间的依赖与重叠，以及缓冲和驻留配置对并发的限制。复用 L0 时，仅补充其边界之外的服务与等待，避免重复计算片上取数成本。
