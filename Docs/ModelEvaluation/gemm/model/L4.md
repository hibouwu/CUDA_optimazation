# L4：算子图执行

[层级总览](../README.md#模型层级) · [统一接口](interfaces.md)

## 系统边界

从算子图输入就绪到所有必要输出完成，比较多个 kernel 与 MegaKernel 等执行方式；中间结果可以按合法的数据共享范围保留在片上，或写入 GMEM。层级按逻辑算子依赖划分：多个 kernel 完成同一个 GEMM 仍由 L3 组合，多个算子融合成一个 MegaKernel 仍需本层描述。

## 建模接口

- 输入：算子依赖图、各节点的计算契约、中间结果位置与生存期、融合边界和调度方式；完整算子引用 [L3](L3.md)；片上融合按实际接口引用 [L1](L1.md) 或 [L2](L2.md)。
- 输出：算子图完成时间、任务吞吐量、峰值存储占用，以及融合前后的数据流量、调度和同步开销。

## 资源与需求

本层引用下层硬件能力，按类别记录新增使用需求。中间张量和任务队列是占用对象；同一容量或带宽限制不重复相加。

### 计算资源引用

计算能力、指令发射和 SM 驻留约束引用 [L0](L0.md) 与 [L1](L1.md)；完整 GEMM 节点引用 [L3](L3.md)。本层记录各算子的计算需求及融合、并行执行时的竞争，不新增一份计算资源。

### 带宽使用需求

| 数据传递 | 资源参数来源 | 本层增加的需求 |
|---|---|---|
| 片上中间结果 | [L1 带宽与数据搬运](L1.md#带宽与数据搬运) | 寄存器、SMEM 及目标支持的专用存储上的实际访问；需满足合法共享范围与生存期 |
| 经 GMEM 传递结果 | [L2 带宽与数据搬运](L2.md#带宽与数据搬运) | 中间结果写入、后继读取及缓存复用后的实际流量 |
| 重排、转换或溢出 | 按实际指令与路径引用 L1 / L2 | 额外计算和搬运需求；与原有任务共用服务能力 |

### 存储占用

| 占用对象 | 容量约束来源 | 本层记录的量 |
|---|---|---|
| 片上中间结果与缓冲 | [L1 存储与缓存容量](L1.md#存储与缓存容量) | 实际分配量、生存期及融合后对驻留的影响 |
| 全局中间张量与工作区 | [L2 存储与缓存容量](L2.md#存储与缓存容量) | 同时存活对象与峰值占用 |
| 缓存中的中间数据 | 对应 L1 / L2 cache 容量与访问模型 | 工作集、复用距离与竞争；不保证持续保留 |
| 任务队列与状态 | 按实际存储位置引用 L1 / L2 | 分配量、生存期及读写需求 |

### 调度与同步开销

| 执行方式或机制 | 使用的服务 | 本层增加的开销与约束 |
|---|---|---|
| 多个 kernel | 启动与依赖管理 | 按计时边界计入启动、依赖等待及 kernel 间数据传递 |
| MegaKernel 任务分派 | 已有指令执行与存储服务 | 分派代码、队列访问、任务粒度与负载不均衡 |
| 原子操作与同步（按需） | 引用实际执行路径与同步机制 | 串行化、等待及算子间完成依赖 |

## 时间模型

算子接口沿用[统一事件与资源约定](interfaces.md)，片上融合须使用匹配的输出/输入可见性和存储生存期。

待推导：任务依赖、资源共享、中间结果生存期与调度共同决定的完成时间。不能将多个强制写回 GMEM 的 L3 时间简单相加来表示片上融合。
