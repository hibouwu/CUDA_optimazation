# 长 K：局部主循环与完整时间

目前缺参考卡上新长 K 形状的后续 L 和匹配的 ends/dual 桥接。校准作业 741159 只采到冻结参照，540 个开发槽位没有执行；参数能否不依赖 G6 独立确定，尚无结论。[测量结果](../../../../../results/gh200_resource_campaign/access_rules/Q15-full-time/long-k-mainline/20261012-R09-long-k-calibration/README.md)与[已结束的测量安排](#measurement-20261012)保留。

本页维护长 K 在频率之外的残差（局部成本不足或组合偏差）及已结束任务的记录。cfg_b G6 完整时间 +35.46% 的主因是有效频率（预测 0.90 GHz、实测约 1.20 GHz，代入实测频率后为 +1.71%），频率的运行前预测与机制由[有效频率任务](../mechanism/hardware_rules/FREQUENCY-MECHANISM.md)负责。

## 要区分的解释

- **局部成本不足：** 对齐窗口和完成端点后，局部残差能解释完整时间缺口，并随静态工作量或执行组织变化。
- **组合存在偏差：** 局部残差不足以解释缺口，误差主要随 CTA 分配、最后完成者或局部到完整时间的转换变化。

cfg_a G6 的冻结频率和完整时间都低估，提高频率会进一步缩短预测时间。first/later L 并非一致低估；模型选出的代表 CTA 比实测最晚 CTA 早结束，结束时刻差距中位约 5.07%。不能预先把完整时间误差全部归为局部周期不足。[R09](../../experiments/gh200_sm90/Q09-frequency/R09-inkernel-clock-stages.md)维护观测边界。

## 已结束的八小时任务规则

以下保留原采用标准，供复现失败版本使用；没有启动新的离线任务或测量。

- 八小时是上限，GPU 预算为 0；最多检验两种事先写定、有静态依据的最小修正。归因完成时、最迟在 3.5 小时处，先记录解释、反例、形式、参数来源及预期，再实现。
- 以 cfg_a G6 为入口，检查 G6 三配置和固定 29 个可评分条件。不添加只对 G6 生效的常数、条件编号分支或实测状态输入。
- 若参数只能由 G6 定价，移除 G6 后无其他数据或静态约束确定它，交付必要测量方案；不能用全数据参数填补该折。外推本身不等于失败。
- 按 M×N 排除该形状全部配置、模式与 K，只重拟合新增组件；其他组件沿用 r2。结果称“组件留形状诊断”，不称完整模型独立留出。
- 保留 29 个条件、7 个拟范围外条件的诊断数值，以及 cfg_c G2 的原拒绝记录。缺值或无法计算不能靠删行绕过。
- 非 128 B 对齐 A/B 行距、非默认 stage（cfg_a/b 为 6、cfg_c 为 4）和原供给不可辨识项仍不支持。7 个范围外条件为 A+16B 三个、B+32/80/112 三个和 stage4 一个；其余 22 个也须满足校准覆盖与原拒绝规则。
- G6 三配置的频率与完整时间误差均须下降。直接影响的分项或关键 CTA 在拟合前写定指标、集合与容许误差，不能被总时间收益覆盖。
- 其他条件的完整时间绝对误差中位数与最大值不增加；任一条件增加不超过 2 个百分点；拟支持范围内原误差 ≤10% 的条件不得变为 >10%。2 个百分点是工程上限，不是噪声界。
- 同时报告频率、时间、换算周期、首段、预填、first/later L、输出、尾段和关键 CTA；窗口先取绝对误差再聚合，保留符号与最坏窗口。组合候选做同样检查。
- 得到候选、缺一个必要测量或没有候选，任一出现即停止；届满时保留未完成检查。原合同不自动进入第四轮离线开发或 V10。

## 2026-10-12 必要校准：已结束

原安排为参考卡 GPU-43269fbc / romeo-a057、V09 协议，18 个新条件、12 组 ends/dual 桥接、冻结参照和 G6 开发复现，共 660 进程；上限 1 个 GPU 提交、wall≤60 分钟，不换卡、不混用其他卡数据。CPU 用 CUDA 12.9.41 完成九个原 plain/dual/ends 构建、最终 SASS／资源与协议检查后提交。[原方案](../../../../../results/gh200_resource_campaign/access_rules/Q15-full-time/long-k-mainline/20261011-long-k-event-bounded/measurement-v2/README.md)

实际 741159 用时 1 分 52 秒，27 个 setup 和 120 个参照进程正常返回；四条 event−包络增量触发原停止门槛，540 个开发槽位未启动。新参数独立定价和固定 29 条件的采用比较未执行。已用提交 1/1，无恢复；失败终点保留，不是 V10。正常采样故障原可按既有规则恢复一次，其余超预算需另经批准，本次没有恢复。[执行记录](../../../../../results/gh200_resource_campaign/access_rules/Q15-full-time/long-k-mainline/20261012-R09-long-k-calibration/README.md)

## 下一次测量应怎样限定用途

先写明要用新数据确定哪个参数，以及哪两个静态条件能区分上述解释，再决定是否复用原 18 条开发条件。不要仅因旧计划有 660 个槽位就原样重跑。

频率预测器可用后，先用它替换 V09 的时钟部分重算长 K 条件；只有替换后的残差仍超过 C3 的事先门槛，才按上述两种解释设计新对照。

局部 L 的有效性取决于窗口端点、指令、完成等待、同 SM 计时、正确性及相关参照。event−包络漂移单独出现时，记录并限制完整时间转换；保留有效的局部开发数据，其能否定价还需检查相关参照和协议桥接。event−包络相对 V09 冻结值的增量随作业变化：10-12 为 +0.688–0.848 µs，10-13 冒烟为 +0.85–3.2 µs，同日另一作业接近 V09。具体检查见[按用途划分的测量检查](../../experiments/gh200_sm90/access_rules/RESEARCH-GUIDE.md#measurement-checks)。

新的作业数量与条件尚未批准。本页不修改 741159 的终态、旧门槛、未执行槽位或 V09 成绩。
