# L3：完整 kernel / GEMM

[层级总览](../README.md#模型层级) · [统一接口](interfaces.md)

## 系统边界

从输入在 GMEM 就绪到整个 GEMM 的输出在 GMEM 完成，包含 L2 的 mainloop/epilogue 组合、初始化、必要同步、任务分配和全 GPU 执行。

输入按 workload 约定的布局提供；方案所需的额外转换计入任务边界。输出完成指满足约定同步条件、可被后继消费者使用，不要求强制刷新全部缓存至物理外存。主机与设备计时范围遵循[问题定义](../problem.md#3-性能指标)。

单 kernel GEMM 的 kernel 完成时间即为任务完成时间。若同一 GEMM 需要额外转换或归约 kernel，仍在本层按任务依赖组合；[L4](L4.md) 按逻辑算子图划分，不按 kernel 数量划分。

## 建模接口

- 输入：完整问题实例、初始缓存与运行条件、L2 阶段配置及事件接口、CTA/cluster 划分、驻留配置、工作 tile 分配与遍历顺序。
- 输出：完整 GEMM 完成时间、FLOP/s 及注明参考时钟的 FLOP/cycle、各通路总流量、资源限制、负载不均衡与尾波影响。

本层组织 L2 mainloop 与 epilogue 的执行次序和合法重叠，包括跨输出 tile 的状态复用。多 CTA/SM 同时使用 L1/L2 的资源时，共享限制只施加一次；由此改变的供给和完成时刻反馈给 L2，不能将孤立单 CTA 的吞吐量直接乘以 SM 数。

## 资源与需求

### 计算资源引用

各 SM 的计算与驻留能力引用 [L0](L0.md) 和 [L1](L1.md)，协作阶段的需求与事件关系引用 [L2](L2.md)。本层增加可用设备规模和任务分配，不复制下层服务率。

### 设备规模

物理 SM 数由硬件文档给定，任务实际可用的 SM 范围属于运行条件。CTA/cluster 数与 persistent worker 数由方案及资源约束决定，不能自动等于物理 SM 数。设备参数见 [Thor L3](../hardware/thor_sm110/L3.md) 或 [GH200 L3](../hardware/gh200_sm90/L3.md)。

### 存储与缓存容量

| 对象 | 约束来源 | 本层增加的关系 |
|---|---|---|
| 驻留 CTA/cluster 的片上分配 | [L1 存储与缓存容量](L1.md#存储与缓存容量) | mainloop、epilogue 和调度状态的同时占用；按实际生存期计算驻留 |
| 全局矩阵与工作区 | [L2 存储与缓存容量](L2.md#存储与缓存容量) | 整个问题及归约、重排等额外工作区的峰值占用 |
| 跨任务缓存工作集 | L2 的缓存容量与访问条件 | 遍历顺序、复用距离、竞争与初始缓存状态 |

### 带宽与数据搬运

| 通路需求 | 服务来源 | 本层增加的约束 |
|---|---|---|
| 全部任务的 GMEM 访问 | [L2 带宽与数据搬运](L2.md#带宽与数据搬运) | 按读写比例与缓存状态聚合请求；外存/L2 cache 共享带宽不按 CTA 或 SM 数复制 |
| 同一 SM 上的片上访问 | [L1 带宽与数据搬运](L1.md#带宽与数据搬运) | 驻留任务与不同阶段同时访问时的竞争 |
| 调度、转换和归约的额外访问 | 对应 L1/L2 通路 | 单独记录执行需求，不能重复计入原 tile 的流量 |

### 调度与同步约束

| 执行机制 | 使用的资源 | 本层增加的约束 |
|---|---|---|
| grid / CTA 调度 | 引用 L1 的 SM 驻留资源 | CTA 分布、波次、负载不均衡与尾波 |
| persistent 工作分配（按需） | 引用已有计算与存储资源 | 任务分派开销和队列访问需求 |
| cluster 协作（按需） | 协作 SM 及各自片上资源 | 协作范围、驻留限制与跨 CTA 同步 |
| 原子操作或归约（按需） | 所选执行与存储通路 | 依赖、串行化和额外计算/流量 |

## 时间模型

按[统一接口](interfaces.md)组合操作和资源事件。每 SM 一个同形 CTA、固定可兑现服务份额的完整周期示例见 [FP32 示例](../schemes/fp32_simt_tiled.md#5-l3完整问题与-flopcycle)；其他并发与缓存条件需重新求解。

待推导：根据 tile 数量、任务映射、驻留与资源共享，将 L2 阶段事件组合成整张 grid 的完成时间；包含阶段衔接、跨输出 tile 重叠、任务分派和最后必要输出的完成条件。

波次与单 tile 时间相乘仅在任务时长、资源供给和调度假设允许时使用。额外转换和归约按其依赖加入完成边界；预测仍以问题要求的有效工作量计算吞吐量。
