# m11：普通 LDS/STS 的地址与执行组织

更新：2026-10-13。**两次冻结留出均未通过，当前不接入正式组合。** 本页维护当前机制候选和重启条件；[R03](../../../experiments/gh200_sm90/Q07-smem/R03-access-demand.md#m11-current)维护测量与历史推导，数值参数仍以各次冻结产物为准。

## 1. 现象

完整 warp 的 bank 地址集合、多重度和返回字节相同，lane 排列仍可使窗口周期接近四倍。后续随机布局区分了结构化开发集无法区分的需求规则；第二次留出的超标集中在 8 B、1 warp 独立读。详细配对、SASS 和计时条件见 R03。

## 2. 假设

| 候选 | 当前判定 | 仍需解释的现象 |
|---|---|---|
| 全 warp 集合或原子组需求标量 | 已被 lane 排列与广播反例否定 | 相同输入映射为明显不同的窗口 |
| 子组 bank 向量、按 bank 合并（v1） | 冻结留出失败 | 随机宽访问需求低估；结构化开发集未能区分 |
| bank 两两不相交才合并、全 warp 同址记一次（v2） | 保留为工作需求假设；配套时间模型整体验收失败 | 8 warp 独立读写子集误差小，但不构成机制唯一或完整通过 |
| 单 warp 时间形式 `P1(D)=max(F,c+sD)` | v2 在支持域内出现反例 | 低 D 偏长、高 D 偏短；还不能判断只需改时间曲线，还是需求/依赖描述缺项 |

## 4. 结论与重启条件

目前采用 v2 的需求规则作为后续研究工作假设，保留需求规则缺项与单 warp 执行时间线缺项两种解释；不采用新的拟合常数掩盖原冻结失败。若目标 GEMM 的 LDS/STS 组织使这一不确定性影响配置选择或时间判断，再立单 warp 区分实验：先固定宽度、指令/消费依赖与循环长度，使需求量接近但布局或依赖不同，给两类解释写出事前预测。现有留出转为开发时须另取新留出。

本轮没有新增 GPU 提交或预算。以下保存早期阶段的测量安排；当时“未执行条件留出”不能用作当前总状态。

## 历史：原任务的测量和验证要求

第一轮修订后的截止为 2026-10-12 巴黎时间 18:00，累计上限 3 个提交，失败 740708 计入。历史实际使用 2 次；新的 lane 对照按[单独的测量安排](#measurement-20261012)计数，不能混用预算。旧启动、失败和授权记录保留在[原记录](../../../../../../results/gh200_resource_campaign/access_rules/Q07-smem/m11-lds-sts/20261011-parallel-bounded-preparation/smem-amendment-20261012.json)。两项任务都已结束。

- CPU 上先用 CUDA 12.9.41 检查最终 SASS：循环内目标 LDS/STS 的数量、宽度、依赖、计时消费者和资源须正确，无 spill；正确性在计时外检查，同址写不得引入未定义竞争。
- 校准和留出用同一 GPU UUID、同一协议，记录实际 SMID。原 stride 和广播数值只作条件对照，不能当跨卡常数。
- 区分地址需求变化与发射／依赖／消费链变化；先写预期，再测最少对照。计时只能支持条件时间关系时，服务批次仍是推导，不能称实测内部事务。
- 使用空窗口、不同重复长度和同步／消费控制，区分固定项与每指令成本。源码中的同步未必形成显式 SASS；以实际二进制为准，不能把复合控制窗口定价成单独同步指令。
- 相对误差中位数 ≤5%、最大 ≤10%，且满足原逐组绝对周期容差、正确性、全部预列条件与协议检查。并列窗口总周期、每条指令周期、误差符号、计时粒度、固定开销和离散程度。
- 冻结前确定源码／二进制、参数、支持范围、协议、全部新地址及预测、seed、指标与 SHA。留出采用新布局，采样后不回调参数、不放宽阈值、不剔除失败。
- 留出还须包含一段受支持的真实 CUTLASS LDS/STS 访问序列，在隔离探针重放。实际为 STSM 等范围外指令时报告缺口，不能用普通 STS 替代后称原序列通过。
- 留出通过、形式被反证或不可辨识，任一终点出现即停止。预算或时间耗尽时报告缺项，不自动扩展到矩阵、多 CTA、跨卡或下一机制。

## 历史：首次冻结前的离线推导

原模型已经按访问宽度划分 128 B lane 子组，并在组内统计冲突。8 B 密集对照连原子组需求都相同，时间仍差 47.381%；16 B 密集对照相差 84.640%。重新使用原子组冲突数不会解决这两个反例。[原模型](../../../../../../microbench/gh200_resource_campaign/access_rules/r03_lds_sts_model.py)与[密集布局反例](../../../../../../results/gh200_resource_campaign/access_rules/Q07-smem/m11-lds-sts/20261012-m11-lane-contrast/run-20261012T110219Z/README.md)可直接复核。

新的假设须明确每一阶段包含哪些 lane 和字、广播如何合并，再给上述反例写出静态预测。若仍把两点算成相同需求，就停止该形式，不先拟合。依赖控制也须解释；时间比例不能唯一确定内部 wavefront 或端口数。

文档收尾后已离线检验一个静态形式：保留子组的 bank 向量，将 Σg maxb 改为 maxb Σg。它区分密集排列，但新标量仍把宽广播与密集交错算成相同输入；两点在原周期容差下无法共享预测，因此没有拟合或采用。[推导、等价约束与反例](../../../experiments/gh200_sm90/Q07-smem/R03-access-demand.md#m11-bank-vector)

以上“未冻结／未提交”仅指 741153 对照及紧随其后的离线阶段。其后已执行下述两次冻结留出，身份、授权与结果以 R03 对应日期记录为准；旧预算不自动延续。
