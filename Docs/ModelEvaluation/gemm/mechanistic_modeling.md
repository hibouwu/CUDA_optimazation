# 当前模型与理想模型的差别

下表中的当前模型指 V09 组合候选；理想模型列表示研究目标。

| 维度 | 当前半经验模型 | 理想机制模型 |
|---|---|---|
| 主要目标 | 预测固定 GEMM 配置的时间，解释部分变化 | 建立可执行机制假设，预测行为并接受实机干预检验 |
| 基本对象 | 聚合供给、计算、输出阶段及 CTA 递推 | 请求、资源、队列、缓冲槽、在途状态和事件依赖 |
| 时间来源 | 估算阶段代价，再组合依赖与重叠 | 按资源和事件规则推进，生成完成时间 |
| 程序与硬件 | 部分软件组织显式保留，其余折叠进参数 | 已知软件依赖与待辨识硬件机制分开表达 |
| 实测与拟合 | 确定条件公式与时间映射的系数 | 排除机制、辨识参数并验证跨条件复用；仍允许拟合 |
| 参数含义 | 部分参数是多个过程合并后的有效代价 | 对应明确机制对象；不可辨识部分保留组合量或范围 |
| stage 变化 | 通过公式或近似权重影响预测，现有响应仍有缺失 | 由槽占用、消费和释放关系产生等待变化 |
| 输入输出交互 | 用聚合重叠关系表达部分影响 | 用请求时间线与候选共享资源解释竞争和相位作用 |
| 跨 CTA 差异 | 条件特征与 CTA 递推，关键 CTA 仍有失配 | 按假设需要保留共享、竞争和状态差异 |
| 频率与周期 | 经验频率模型与事件包络联立 | 分别声明执行与时钟机制的范围；仍用经验时钟时明确这部分边界 |
| 更换执行组织 | 聚合参数可能需要重新校准 | 尽量复用硬件机制，改变程序图；超出范围时扩展机制或条件参数 |
| 验证依据 | 完整时间、分项和关键 CTA，现有整体未通过 | 事件顺序、等待位置、干预响应、完整时间与参数复用能力 |
| 多个相容解释 | 采用当前组合候选，存在其他开发分支 | 明确首选工作假设，归档少量备选及重启条件 |
| 能够声称的结论 | 声明范围内的预测精度及有独立证据的局部解释 | 哪些机制预测通过、哪些竞争解释被排除，以及剩余不确定性 |

目标与通用原则见[GOALS](GOALS.md)，推进顺序见[PLAN](PLAN.md)，当前候选状态见[MODEL-CANDIDATES](model/semi_empirical/MODEL-CANDIDATES.md)。
