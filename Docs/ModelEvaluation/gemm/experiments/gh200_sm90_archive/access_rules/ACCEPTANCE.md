## R04阻断证据与修复范围

受审源为`20261006-A-job735062/r04-formal-v3/build/r04.sass`，完整SHA和片段见[动态计量发现](../../../../../../results/gh200_resource_campaign/access_rules/acceptance-20261006/R04-dynamic-work-findings.txt)。

| 函数 | 机器码事实 | 对声明工作量的影响 |
|---|---|---|
| `_Z5jointILi3ELi3...`，CVT-only | F2F在0x350/370/390/3a0；回边0x420→0x3c0 | 转换不在重复循环内，不能计160×repeats转换/lane |
| `_Z5jointILi2ELi2...`，LDS-only | LDS在0x320；回边0x370→0x2d0，没有na内层循环 | 每repeat只有一次LDS，而非160次 |
| `_Z5jointILi3ELi0...`，LDS+CVT串行 | F2F位于0x370/390/3c0/3e0，外层回边0x4f0→0x3f0；LDS仅一次/repeat | 转换外提、请求合并，原比例解释不成立 |
| Family3交错 | 时钟窗口中没有F2F | 转换在窗口外，不是所声明的联合服务 |

数值正确、hash一致、时钟间出现静态指令都不能替代动态计数。原“CVT混合慢5.36%/9.82%”结论暂停。A负责先修防CSE的真实访存/逐action转换和必要消费，再按各比例的CFG确认次数、短正确性和正式复测。只重测受影响范围；WGMMA数据按已记录条件保留。

C7520来自divergent-path的compiler WG.AR；V01另有C7517用于安全寄存器消费。它们不是数值错误，但改变实际等待序列。A先尝试最小修正；保留旧序列时也可查表，不能仍按理想在途group解释。
