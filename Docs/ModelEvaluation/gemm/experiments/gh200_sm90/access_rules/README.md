# GH200 访问规则与 GEMM 时间预测

## 当前结论

**[V09](../Q15-full-time/V09-component-validation.md) 整体未通过。** 同卡30条件全部测完，29个受支持预测为 **4.11% / 35.46%**，另1个保持冻结前拒绝；不能把子集当作整组通过。最大误差来自cfg_b长K有效频率迁移，另有A/B行距响应失配；总时间还存在分项误差抵消，不能单凭4.11%的中位数判断机制准确；分项与关键CTA仍有错误。

此前 **V08 整体未通过。** 同一张 GH200、固定 CUTLASS cfg_a/b/c 配置的 36 个新留出条件，总时间绝对相对误差中位数 **2.61%**、最大 **35.34%**，未达到 5% / 10% 目标。失败主要涉及 A/B 行距未按 128 B 对齐、swizzle=8 的整 cluster 补齐 tile，以及 cfg_b 大足迹长 K。跨卡尚未验证。

测后按 swizzle=1、A/B 行距为 128 B 倍数、K ≤ 16384 限定出的 21 个条件为 **1.90% / 6.04%**；这是完整留出集的子集分析，不是独立验证，也不代表整轮通过。逐例结果及后续对照见 [V08](../Q15-full-time/V08-wider-validation.md)。

[V07](../Q15-full-time/V07-rule-validation.md) 在同卡、cfg_a/b/c、swizzle=1、K 位于校准范围内的 24 个条件（12 个不同 M×N）上为 **3.06% / 8.71%**，总时间通过；供给、末次输出和关键 CTA 定位仍失配，20/24 预测偏长。它使用 V06 事件递推、同卡重新校准与 R18 边界修正；R19 只作诊断，R02/R11/R12/R16/B01 未用于 V07。

现行V09候选的公式、输入与限制维护在 [MODEL-CANDIDATES](../../../model/semi_empirical/MODEL-CANDIDATES.md#v09-model)；[RULES](RULES.md)只收通过独立留出的规则。[离线消融](../Q15-full-time/V01-validation.md#v09-ablation)暂不支持整体退回聚合模型，但不覆盖行距、边界和分项失败。两项后续测量已结束：主线只完成参照，必要长K开发数据未采到；m11 随后已完成两次冻结留出，均未通过；当前候选与评分入口见[M11-SMEM](../../../model/mechanism/hardware_rules/M11-SMEM.md)。[一页计划](PLAN.md)列出当前结论和开放问题；任务细节见[主线](../../../model/semi_empirical/MAINLINE-LONG-K.md)、[m11](../../../model/mechanism/hardware_rules/M11-SMEM.md)，已执行的范围与预算并入各自任务文件。实际分工与状态见 [EXECUTION](EXECUTION.md#status)，V09原采样和失败评分保持。
