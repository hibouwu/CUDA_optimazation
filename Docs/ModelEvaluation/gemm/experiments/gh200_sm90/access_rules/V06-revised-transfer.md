# V06：修订后的迁移验证

FP16→FP32、α=1、β=0、`ElementC=void`、persistent、CUTLASS 3.9.2、`-DNDEBUG`。cfg_a 128×128×64 cooperative 2×1（6 stage），cfg_b 128×128×64 pingpong 1×1（6 stage），cfg_c 256×128×64 cooperative 1×2（4 stage）。校准、冻结、留出测量都在作业 736868（romeo-a043，GPU-201f9d2a）内完成。

**结论：未达标。** 18 个留出点 µs 误差 |e| 中位 5.25%、最大 18.96%（目标 ≤5%、≤10%）。时钟误差中位 2.3%、最大 4.6%；剩余失配来自 cycle。

## 模型

T = F + C/f。C 为各 CTA 入口→最终源释放 cycle 的最大值，tile 列表由 CUTLASS 静态调度器推出。每个 CTA 按事件递推：

- 起点：fm₀ = P0 + S，P0 为入口→producer 首次取得工作，S 为该点→首 tile 首 MMA。
- 主循环：me = fm + L，L = l0 + l1·Kt（V05 形式，首 tile 另加 dL0）。
- cooperative：ep = me + w；ed = ep + E（首 tile 用 E0）；下一 tile fm = ed + h。
- pingpong：fm_j = max(me_{j−1}+gm, ed_{j−2}+h)，ep_j = max(me_j+w, ed_{j−1}+we)。epilogue 单独运行时工作量为 E；与另一组下一 tile 的主循环重叠时，按速率 r 推进。
- 末尾：end = max(ed) + Etail + X。X 是最慢 CTA 相对中位区间 CTA 的超出量，从 {0, 常数, ∝B, x0+x1·T} 中按校准留一 RMS 选择；在 0.2 pp 内取参数较少者。

时钟沿用 V03 形式：f = a − b·φ·ln W − c·D − d·μ。b=0.035340、d=0.387158 取自 V03 冻结文件（`configs/v03-predictions.json`）；D 的 L2 有效容量 30 MiB 也来自该文件。D 估计按 tile 形状推广：每波计入触及的 A/B panel。φ、μ 由本模型计算。

**本卡只重拟合两项**：加性偏置 da = −0.0787 GHz（a: 2.2287→2.1501）和 D 系数 dc（c: 0.0859→0.0268）。预定规则：offset+D 的留一 RMS 比 offset 低 >0.2 pp 才拟合 dc；本次 2.8% 对 4.0%。原因：L2 抖动区（c9）D 被高估，实测 1.55–1.61 GHz，原规则给 1.35–1.51。F 取校准 stamped 进程的 event 时间 − 关键窗口，按配置取中位：cfg_a/b/c = 4.74/4.03/4.99 µs。

## 校准

9 个尺寸×3 配置：1536×2816×{512,4096,16384}、3072×5632×{256,2048}、6144×5632×1024、6144×11264×2048、2816²×1024、8192²×2048（L2 抖动区）。全部为 132 CTA 满 grid，不是留出尺寸。每例 plain 与 stamped 各 7 个进程，交错运行，共 378 个进程；1 个 plain 进程预热不收敛。

stamped 每 CTA 记录：入口、producer 首次工作、每 tile 每消费组的首 MMA/主循环结束/epilogue 许可/完成、最终源释放；只有入口和末端读 globaltimer。stamped 相对 plain 的扰动中位 0.9%、最大 4.3%。校准内 µs 中位 2.9%、最大 6.6%。

模型形式由两次开发作业（736798、736850）在校准尺寸上确定，没有测量留出尺寸。开发中改了三处：pingpong E 用速率模型；逐 tile 区间取均值；增加 X 和 c9。736850 与正式作业同卡。

## 事后诊断（不回填预测）

- **cfg_a 越界补齐行。** 两个大失配的 tile 行数都是奇数（9、11）。cluster 2×1 补齐出整行越界 tile；含越界 tile 的 cluster 主循环为 688–797 cycle/Ktile，其余 CTA 中位 579–602，而模型为约 512。与 V04 中 cfg_a 的 pad_fills_wave 边界案例现象一致（只限 cfg_a 这一例；V04 中 cfg_b 在 2600×3000×2000 的变慢另有 R10 的行距证据，不归为同一原因）；校准集 cfg_a 的 tile 行数全为偶数，未覆盖。cfg_b 同尺寸为 515。排除这两例后中位 4.5%、最大 7.3%。后续 [R17](R18-cluster-boundary.md#r17) 定位了原因并给出规则，代入后两例为 −4.7%、−6.7%（非留出检查）。
- **CTA 间离散（独立问题）。** cfg_b 大输出、尾部的最慢 CTA 比中位 CTA 长 8%、13%，超过校准中的 X（2.2%）。这需要解释离散的来源，不能只把余量改大来吸收。
- 只换入实测 cycle（保留冻结时钟与 F）时 µs 误差最大 5.9%；只换入实测时钟时最大 19.4%：失配在 cycle 侧。
- S 随同时启动的 CTA 数变化：不满波实测 1270–1776，冻结值 2299–2894。

## 未解决

- cfg_a 越界 tile 拖慢 cluster 主循环的机制（多播、越界 TMA 填零）未隔离。
- 最慢 CTA 的离散度在 L2 抖动和短 K 下偏大，目前没有可预测的规则。
- D 估计在 L2 抖动区偏高，本次靠重拟合 dc 吸收；读写 DRAM 流量没有单独测量（未用 NCU）。
