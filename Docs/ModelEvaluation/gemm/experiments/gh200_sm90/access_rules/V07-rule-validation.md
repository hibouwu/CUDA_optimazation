## 模型实际使用了什么

沿用V06的cooperative/pingpong事件递推，在当前卡重新校准初始供给、主循环、epilogue、交接、CTA尾差候选和频率规则。CTA尾差仍在none/常量/比例/tile数线性四种形式中按校准留一误差选；此次三个配置均选择none。该选择不意味着最慢CTA没有离散，而是当前拟合没有取得稳定可迁移的额外项。

R18边界规则使用相同物理tile的窗口差，首/后tile和边界、伙伴、同列/同行类别分别处理；两个K点冻结为插值假设，只在Ktile 16–128内使用，不导出硬件斜率。轻量修复组使用自己短/长K的匹配对照。增量沿cooperative依赖传播一次，不把窗口平均cycle/Ktile再加到旧截距上。

12个边界目标有一类首轮`other`位置没有直接R18支持：它们不与本轮已观察的边界位于同一列/行，冻结模型对该项使用零附加值，并在`boundary_unknown_cells`明确保留。完整时间通过没有补上该局部机制证据。

全部目标为swizzle1，具体stride、shape与配置在预测文件的row中冻结。cfg_a/c的部分边界有效比例不同于校准组；这是本次迁移检验的一部分。cfg_b覆盖近单波、多波、输出规模与尾部分布，未把R19的swizzle8补齐变化当成通用缓存系数。

### 冻结递推怎样手算

令`fm/me/ep/ed`分别为首次MMA、主循环结束、epilogue许可与调用返回。cooperative按下式递推：

```text
fm[0] = P0 + S
me[j] = fm[j] + l0 + l1*Kt + (j==0 ? dL0 : 0) + Δ[j]
ep[j] = me[j] + w
ed[j] = ep[j] + (j==0 ? E0 : E)
fm[j+1] = ed[j] + h
C_CTA = max(ed) + Etail + X
```

pingpong的MMA起点改为`max(me[j−1]+gm, ed[j−2]+h)`，不存在的前项不参与；epilogue许可为`max(me[j]+w, ed[j−1]+we)`。输出工作E在与另一consumer主循环重叠时按校准比例r推进，其余时间按1推进。r是该执行组织的服务参数，不是物理端口常数。

`cfg_a_aligned_k1536`有14×15=210个tile，78个CTA处理2个、54个处理1个，Kt=24。冻结参数给出供给5262.25、首/后主循环12764.25/12722.7865、两次许可各140.6683、首/后输出2401.25/2161.1395、一次交接819.7178、末尾504 cycle，X=0、Δ=0。相加得到`C_max=36,916.7305 cycle`。该形状的冻结频率解为1.7690302 GHz、固定项4.6800005 μs：

```text
T = F + C_max/(1000*f_GHz)
  = 4.6800005 + 36916.7305/(1000*1.7690302)
  = 25.5483441 μs
```

这里的f由当前卡校准规则求解，不是事后代入该留出点的实测频率。另一个明确例子是cfg_a整块越界首tile伙伴的插值：两个合格窗口差1936 cycle（Kt16）和21776（Kt128）给出`Δ=-898.2857+177.142857*Kt`；Kt96时为16107.4286 cycle，只添加一次。负截距属于有限区间的插值描述，不是负硬件延迟；局部迁移资格仍看下面的分项结果。

## 分项与关键CTA定位

分项统计对象明确固定：供给、主循环和末次epilogue/尾段，比较冻结模型所选CTA的预测与该同一CTA的实测；关键CTA最大周期量另与所有CTA的最大时长比较。这样不会在测量后换一个CTA使分项看起来更好。交接h沿用校准的事件定义，单独比较。

| 量 | 定量计分例数 | 绝对误差中位/最大 | 判定 |
|---|---:|---:|---|
| 最大CTA周期量 | 24 | 1.58% / 8.71% | 通过10%/20% |
| 初始供给 | 24 | 12.03% / 45.92% | 未通过 |
| 主循环累计窗口 | 24 | 1.47% / 16.57% | 通过 |
| 末次epilogue调用窗口 | 24 | 12.44% / 46.82% | 未通过 |
| 交接h（≥512cycle） | 17 | 0.19% / 4.64% | 该子集通过 |
| 末尾短段 | 0（24例均<512cycle） | 保存原始周期误差 | 不凭百分比授予通过 |

供给失配的具体例子：`cfg_b_near_short`预测5334.125、实测3655.5 cycle，多1678.625，即45.92%。输出失配：`cfg_c_partial_odd_k6144`预测4651.964、实测3168.5，多1483.464 cycle，即46.82%。把跨校准形状的统一供给/输出常数用于具体关键CTA和边界，尚未取得分项迁移资格。

24个末尾短段按原始差值和事件关系保留。例如cfg_c若干条件预测536.375、实测267 cycle，差269.375；不能因为绝对时间短就判为模型正确。另7例没有观察到h约束绑定的事件：近单波的两个pingpong形状没有第三个tile，其余5例由前一tile的MMA约束占主导，未暴露同一consumer前次epilogue返回的h窗口。它们标为`not_observed`，不能当作h=0或低误差通过，也不与17个可观察窗口混算“全部通过”。

还发现独立的CTA定位限制：`cfg_a_oob_k6144`中，冻结选择的CTA12实测时长，比真正最长CTA的时长中位数短23,255 cycle，约17.28%；`cfg_a_partial_odd_k6144`也约17.28%。这不是仅凭CTA编号不同否定模型，而是所选CTA时长有实质差距。最长clock64窗口和globaltimer最晚退出CTA的计数分别保存。最大周期量接近仍可能伴随局部窗口高估、关键CTA选错，不能把总时间达标解释成整个事件图已闭合。
