# 当前计划：GH200 GEMM 时间预测的剩余误差

更新：2026-10-08。

## 现状

[V07](V07-rule-validation.md) 在同一张 GH200、固定的 cfg_a/b/c 配置、swizzle=1、K 位于校准覆盖范围内的 24 个留出条件上，总时间绝对相对误差中位数为 3.06%，最大为 8.71%。这些条件包含 12 个不同的 M×N；尚未验证更广泛的形状或跨卡适用性。

预测为 T = F + C_max/f。进入 V07 的是 V06 事件递推、当前卡重新校准的参数和 [R18](R18-cluster-boundary.md) 边界修正。R02、R11、R12、R16、B01 已测，未用于 V07 预测，不在本计划内。

## 剩余误差

| 项 | V07 中位 / 最大 | 例子 |
|---|---|---|
| 初始供给 | 12.03% / 45.92% | `cfg_b_near_short` 预测 5334、实测 3656 cycle |
| 末次输出 | 12.44% / 46.82% | `cfg_c_partial_odd_k6144` 预测 4652、实测 3169 cycle |
| 关键 CTA 定位 | 两例约 17% | `cfg_a_oob_k6144`、`cfg_a_partial_odd_k6144` 所选 CTA 比实际最慢 CTA 短 |
| 共同偏差 | 20/24 偏长，cfg_c 8/8 偏长 | 主要为打点开销，见下 |

总时间达标而分项误差大，离线诊断证实存在相互抵消。

## 1. 离线分析（已完成）

结果见 [V07 事后诊断](V07-rule-validation.md#事后诊断总时间为何接近离线不改判定)：

1. 20/24 偏长主要来自打点开销：模型参数取自 stamped 进程，评分对 plain；对 stamped 比较只有 14/24 偏长，F 改按 plain 校准后为 1.87%/4.33%、13/24。
2. 普通 CTA 偏长 2.35%（供给、末次输出取校准常数，校准集偏大形状），最慢 CTA 超出量 1.56% 未建模，二者相抵。
3. cfg_a 边界形状的最慢 CTA 不是边界 tile 所在的 CTA；第 0 轮的变慢分档出现在由形状决定的一组 cluster 上，R18 的按 tile 增量无法定位。

## 2. 改模型

| 改动 | 依据 |
|---|---|
| F 按 plain 进程校准（plain 时间 − stamped 窗口） | 诊断 1 |
| 供给 S 随输入在 L2 中的驻留变化；末次输出随同时输出的 CTA 数变化 | 诊断 2；先在现有校准点上检查能否用足迹 / 同时输出数解释 |
| 校准集加入单波、小足迹形状 | 诊断 2，现校准集缺这一段 |
| 恢复最慢 CTA 超出项，cfg_a 边界形状单独取值 | 诊断 2、3 |
| cfg_a 边界改为“第 0 轮最慢一档”的幅度，不再按 tile 位置定位 | 诊断 3；幅度随 K 和形状的变化需补测 |

改后重新冻结，在新的留出集上测试；V07 的 24 点不再用于判定。

## 3. 验证顺序

1. 同一张卡、更多样的形状：更多 M×N、K 超出校准范围、swizzle≠1。
2. 之后单独做跨卡验证：先只用原参数预测，再看哪些项需要在新卡重新校准。

目标保持总时间中位 ≤5%、最大 ≤10%。

## 何时补测

现有数据分不开时才补测，只针对那一项：

- cfg_a 第 0 轮最慢一档的幅度如何随 M 行数、N 列数和 K 变化（现只有 V07 与 R18 两组形状）。
- 供给是否由 L2 驻留决定：同一形状在 warm 与调用前清 L2 两种条件下对比。

补测先冻结预测再测量。

物理 RF 端口、缓存命中率、所有访问路径达到 Thor 分析深度不属于当前目标；需要时另立目标。
