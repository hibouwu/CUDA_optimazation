# 当前计划：GH200 GEMM 时间预测的剩余误差

更新：2026-10-08。

## 现状

[V07](V07-rule-validation.md) 在同一张 GH200、固定的 cfg_a/b/c 配置、swizzle=1、K 位于校准覆盖范围内的 24 个留出条件上，总时间绝对相对误差中位数为 3.06%，最大为 8.71%。这些条件包含 12 个不同的 M×N；尚未验证更广泛的形状或跨卡适用性。

预测为 T = F + C_max/f。进入 V07 的是 V06 事件递推、当前卡重新校准的参数和 [R18](R18-cluster-boundary.md) 边界修正。R02、R11、R12、R16、B01 已测，未用于 V07 预测，不在本计划内。

## 剩余误差

| 项 | V07 中位 / 最大 | 例子 |
|---|---|---|
| 初始供给 | 12.03% / 45.92% | `cfg_b_near_short` 预测 5334、实测 3656 cycle |
| 末次输出 | 12.44% / 46.82% | `cfg_c_partial_odd_k6144` 预测 4652、实测 3169 cycle |
| 关键 CTA 定位 | 两例约 17% | `cfg_a_oob_k6144`、`cfg_a_partial_odd_k6144` 所选 CTA 比实际最慢 CTA 短 |
| 共同偏差 | 20/24 偏长，cfg_c 8/8 偏长 | 主要为打点开销，见下 |

总时间达标而分项误差大，离线诊断证实存在相互抵消。

## 1. 离线分析（已完成）

结果见 [V07 事后诊断](V07-rule-validation.md#事后诊断总时间为何接近离线不改判定)：

1. 20/24 偏长主要来自打点开销：模型参数取自 stamped 进程，评分对 plain；对 stamped 比较只有 14/24 偏长，F 改按 plain 校准后为 1.87%/4.33%、13/24（看过 V07 后选的；按校准留一选择后效果更小，见第 2 步）。
2. 普通 CTA 偏长 2.35%（供给、末次输出取校准常数，校准集偏大形状），最慢 CTA 超出量 1.56% 未建模，二者相抵。
3. cfg_a 边界形状的最慢 CTA 不是边界 tile 所在的 CTA；第 0 轮的变慢分档出现在由形状决定的一组 cluster 上，R18 的按 tile 增量无法定位。

## 2. 改模型

### 已做：只用现有校准数据的候选（V08 候选）

[`v08_fit.py`](../../../../../../microbench/gh200_resource_campaign/access_rules/v08_fit.py) 复用 V07 校准进程，两处改动都按校准留一选择（参数最少且在最优 0.2 pp 内），[结果](../../../../../../results/gh200_resource_campaign/access_rules/20261008-V07-job737122-v1/reanalysis/v08-candidate-v1/candidate.json)：

| 改动 | 校准留一 | 选择 |
|---|---|---|
| 主循环斜率加入首 tile 窗口联合拟合 | cfg_a 1.76%→2.03%，cfg_b 10.52%→10.22%，cfg_c 2.23%→2.80%（周期 RMS） | 仅 cfg_b 采用 |
| 时间换算对 plain 校准 | cfg_a：stamped_F 1.85%，plain_F 4.04%，线性 2.52% | cfg_a 保持 stamped_F |
| | cfg_b：4.92% / 4.27% / 5.61% | plain_F（3.10 µs） |
| | cfg_c：2.58% / 3.29% / 2.20% | 线性（4.26 + 0.992·W µs） |

在 V07 留出点上事后检查：|e| 中位 2.29%、最大 7.63%，18/24 偏长（V07 为 3.06%/8.71%，20/24）。cfg_c 降到 +1.3%～+2.5%，cfg_b_near_short 从 +8.71% 到 +4.08%；cfg_a 不变，k1536 仍偏长 2.3%～7.6%，主要是供给多算约 1000 cycle。这只是事后检查，不是验证。

结论：现有校准数据能支持的改动有限。cfg_c K=6144 留出点的斜率偏差（多算约 17 cycle/Ktile）在校准中没有被留一识别出来，因为 cfg_c 的后续 tile 只有 Kt 16/32；cfg_a 的打点开销随形状变化，不能用一个常数换算。

### 需要新数据才能做

| 改动 | 需要的数据 |
|---|---|
| 供给 S 随 L2 驻留变化；末次输出随同时输出的 CTA 数变化 | 足迹和末轮活跃 CTA 数可控的形状；warm 与调用前清 L2 对照 |
| 校准集加入单波、小足迹形状；cfg_c 加入长 K 多 tile 形状 | 新校准点 |
| 打点开销 | 同形状 plain 与 stamped 的差随形状的变化；或改用更轻的打点（R18-lite 方式） |
| 恢复最慢 CTA 超出项，cfg_a 边界改为“第 0 轮最慢一档”的幅度 | 不同 M 行数、N 列数和 K 的 cfg_a 边界形状 |

这些补测合成一个作业：新校准点与上述对照一起测，再用新校准冻结模型，最后在同一张卡（romeo-a043，GPU-099dda56）上测新的留出集。V07 的 24 点不再用于判定。

## 3. 验证顺序

1. 同一张卡、更多样的形状：更多 M×N、K 超出校准范围、swizzle≠1。
2. 之后单独做跨卡验证：先只用原参数预测，再看哪些项需要在新卡重新校准。

目标保持总时间中位 ≤5%、最大 ≤10%。

物理 RF 端口、缓存命中率、所有访问路径达到 Thor 分析深度不属于当前目标；需要时另立目标。
