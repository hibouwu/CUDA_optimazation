# 全家族短正确性与正式计量接入约定（草案）

本修订解决 S12 已通过全配置短正确性、但正式总控尚不能使用其适配器的问题。复用原 `run_suite.py` 的归档、锁、进程清理、预热和统计，不另写一套采样循环。本文须经独立 A 审查，代码及负例经独立 B 审查后才允许新的 GPU preflight。

## 版本和旧工件

新增独立合同 `async_copy_formal_v1.json`，显式指定 `adapter_id=async_copy_formal_v1`、`execution_revision=family-b3-v1`，引用原 S12 合同、固定短 profile、B3 审查及 coverage 的路径和哈希。原 `async_copy.json` 和短 `case_diagnostic` 入口保持原语义，不把 B3 依赖塞进它们，避免短检查需要先通过自身审查的循环。

新合同保持原 24 个 case、工作量、8192 轮、CUDA 编译参数和探针不变。变更只涉及运行准入和离线审计；必须核对受审 B3 的 contract case 集合与新合同完全相同。S12 正式适配器独立文件负责 Q 只计一次、方向分别 Q、consumer 另计及资源/计时/正确性字段检查。

总控只增加一个显式适配器注册和一个按 `execution_revision` 选择的 B3 策略。不通过临时 monkeypatch 替换 adapter、审查函数或快照加载函数。旧 run 根据其快照执行原代码；旧结果及审查文件不改写。修改核心文件后，新增 S02/S03 B 审查文件绑定新版本，旧版本门禁保留。新创建运行所用核心版本必须有相应新审查，不能以旧哈希门禁认证修改后的代码。

## 运行前必须证明什么

1. 初始化在启动任何设备程序前，验证 B3 审查独立性、状态、stage/phase、全部 `gate_files` 及 coverage 哈希；不只检查一个 `pass` 字段。
2. coverage 的 24 个 case 恰好覆盖合同，没有重复、缺项或额外配置；每点两次固定短 launch 的成功、参考、seed、完成检查及资源均有绑定证据。
3. 原合同、目标源码、完整设备头文件依赖、独立参考和短 profile 均与 B3 绑定一致。运行器的纯主机侧扩展单独经新 B 审查，不因增加适配器要求重做相同短启动。
4. 构建后、第一次 pilot/预热前，再核对实际目标 SASS 和资源、设备/工具链身份。允许整体可执行文件因未使用的宿主代码不同而改变，但目标指令、其依赖与 ABI 的复用必须有明确独立证据；不能只比文件名或 kernel 名。
5. 固定长度 S12 不做长度搜索。新 preflight 在 B3 与接入源码 B 通过后运行原 24 点，用于 B4 长循环正确性、计量和预热观察；完整家族 B 通过后才可启动十进程正式采样。

## 快照、恢复和离线审计

B3 review 本体、coverage 及其传递绑定文件全部进入新 run 快照。路径解析始终以受检 run 的冻结仓库为根；移动整个 run 后可离线核验，不回查可变工作区。

`initialize`、首次执行、`resume`、离线 `load_run/audit` 使用同一策略确定必需 review 集合，且检查集合精确一致。已有失败收据不被新采样覆盖。恢复到已编译或已有样本阶段也必须核验 B3 和身份，不能利用检查点跳过准入。

完成记录继续由原 finalizer 在完整 C 审查后产生。B3 通过只授权 B4，不能直接产生 COMPLETE 或合格性能标量。

## 必需负例与独立审查

CPU 检查应拒绝缺失/损坏/非独立 B3、缺 case、重复 case、失败输出、profile/参考/source 漂移、SASS/资源/设备不匹配、遗漏传递依赖以及恢复绕过。应证明拒绝发生在第一次 pilot/预热进程之前。搬目录重放必须使用冻结依赖；改变可变工作区不影响原归档核验。

回归需覆盖现有六类 adapter 的旧语义、旧 `case_diagnostic` 不依赖 B3、旧完成归档可继续通过原冻结入口。核心源文件变更引起新的门禁哈希，是核心版本更新的证据要求；不作为重测已封存 GPU 数据的理由。

当前短诊断运行器的 `CORE_REVIEW` 也绑定共享核心文件。集成 B 验收须为新建 `case_diagnostic` 配置新的 early-validation core B 门禁；旧冻结诊断仍用原 r2，新短诊断仍不要求家族 B3。不得只更新正式运行的 S02/S03 B 而留下已失效的短诊断核心门禁。S12 集成适配器的新 ID 和新增策略另签集成版审查，原 source-only 门禁保留其原哈希范围。
