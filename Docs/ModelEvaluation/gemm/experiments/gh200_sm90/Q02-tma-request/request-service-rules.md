# 单 CTA 请求服务的规则检验

25 个目录（10-18、10-22）：用已测的行距、长度与预填数据，检验覆盖计费、准入、返回、在途信用、源片段流水等服务形式。多为 CPU 闭式界或有限回放；single-b-general-bound 含留出采集。原 row-stride 族的一部分。

## 结论

- 现用源服务在全部 local 命中时，base/B32/B80 的请求时间线逐值相同，行距响应为 0（source-isolation、plain-release、resident-sector）。
- CPU 闭式必要界排除的固定形式：同一展开图上的非负线性覆盖价；本 CTA 3/6/9 信用；源后补齐 FIFO；静态 home 价格；单边前段；固定返回边与完成尾；公共尾重分配；统一共享吞吐；同版控制分配。
- 字节基价 + 额外覆盖价（excess-coverage，λ、β32、β128、h、K 五个参数）在 Q1 的 16 项开发约束内最大误差 4.375%；固定参数连续到 Q4 时，首次预填增量预测 677.08、实测 513 cycle，误差 31.98%，该连续形式停止，没有独立留出。
- 发布与源 start 分离的两种入队容量（固定形式）、源片段／目的行的三种结构与源字节流水（各一次有限拟合）均停止，没有进入 Q4 或 GEMM；停止的是参数版本或固定形式，不构成结构反证。
- 单 B 一般增长界（752491）：增长 2979 cycle 落在两区间之间，信息不足。
- 本组规则没有接入 GEMM。
