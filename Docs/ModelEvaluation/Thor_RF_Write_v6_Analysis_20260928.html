Thor RF 写回：v6.2 结果与当前结论

更新：2026-09-29 · NVIDIA Thor / sm_110a · 两批，每条件 16 次 · 1,728 次正式采样、216 次门禁检查

本轮已确认：在被测的高吞吐独立计算结果流中，四种目的布局与 32／64／128 个连续前缀结果，没有产生可观测的额外推进限制，也没有改变目标结果的可用性。

这一结论有范围：单 warp、32 bit 标量结果、32 个背景目的、指定供给节奏和同址预热条件。不同路径返回的通用限制规律尚未闭合；目前只能保留条件明确的局部观察，不能把它写成统一 RF 写惩罚。

直接回答最初的三个问题

问题当前得到的结论怎样量化／边界
目的寄存器布局会不会限制推进或可用？连续、偶数、奇数、步长 4 的背景目的布局，在本轮没有改变推进窗口或目标正确性。576 组布局配对窗口差全部为 0；其中 288 组目标观察配对，可用性判定完全一致。目标 marker 固定 R168，并非枚举所有目标寄存器。
结果数量会不会带来额外限制？固定计时结构下，连续前缀结果数从 32 增到 64、128，没有新增推进延迟，也没有推迟被测目标的可用性。普通目的的 384 组数量配对窗口差全部为 0；其中 192 组目标观察无变化。这里改变的是连续结果流长度，单条结果宽度与每条指令的结果数未改变。
不同路径返回会不会影响推进或可用？既有 v6 证实了特定返回条件下的局部消费交互；本轮未新增跨路径测试。v6：特定目标/gap 下，有 EX2 时目标消费者窗口 33 周期，预装值/NOP 为 32；不能推广成任意路径碰撞加 1。
现在是否已有完整统一写规则？还没有。布局与连续数量在本轮范围内已有明确结论；跨路径返回限制仍只有条件性证据。缺的是返回与消费的实际时间关系，以及这些条件怎样引出限制；不要求为回答功能问题先还原全部物理端口。

本轮覆盖范围：什么确实被改变，什么保持固定

生产者均为高吞吐独立 FADD：普通源寄存器读取为零，生成 32 bit 标量结果。单 warp，背景目的池大小 32；每次正式测量前，同一代码地址执行 32 遍。每遍重置 marker 和观察寄存器，只捕获最后一次观察结果。

对照轴实际改变保持固定
布局，N=128R8…R39；R8,R10,…R70；R9,R11,…R71；R8,R12,…R132只改目的字段。指令、结果数量、控制字段、目的重访距离 32、marker R168 与消费者相同。未假定这些编号对应何种物理 bank。
数量，连续布局128 个前缀位置的最后 N=32/64/128 个是 FADD，其余为 NOP计时边界、128 个指令位置及各自 stall=1 固定；最后 32 条前缀、marker 和三条后缀保持相同。
辅助对照，RZ背景结果写 RZ；marker 仍写普通寄存器同样的三种 N、两个代码位置与观察间隔。RZ 不是已经证明的完整返回旁路。
位置与观察整个测量结构平移 +48 字节；目标 MOV 或同位置 NOP；gap=4/5/6位置内分别比较布局和数量，目标/NOP 的控制字段保持相同。

因此，普通目的组每个测量区间生成 N+4，即 36／68／132 个 warp 级标量计算结果；每个结果对应 32 个 lane 的 32 bit 值。这里没有改变同时返回的结果数或结果宽度。数量组也改变了计算执行活动，所以即便将来观察到数量差异，也不能直接除以 N 得到“每结果 RF 成本”。

推进：所有正式观测都等于机器码控制间隔之和

W = 7 + 128 × 1 + g + 7。两个 7 分别来自起始时钟和观察槽的实际控制字段；128 个前缀槽无论是 FADD 还是 NOP，stall 都为 1；g 来自 marker 及随后三条 FADD 的控制字段之和。所有项均来自上传机器码，不含拟合开销或经验系数。

在本轮测过的离散点里，gap=5 是跨两个位置均通过的最小设置。gap 是程序化控制间隔坐标，不能命名为“RF 写延迟 5 周期”。相同 146 周期总窗口对应相反正确性，已经直接证明：总推进时间不能替代结果可用性约束。这是观察结果是否可用所必需的检查，不扩展为独立的数据依赖模型。

v6.1 的 8 个正式锚点均复现。与旧 v6 不同，本轮已建立同址预热及控制字段一致的对照，因此本轮的布局／数量结论不再依赖旧 308 周期窗口。现有证据足以结束这个范围内相同布局／数量扫描；无需为了重复零差值再跑同一矩阵。

不同路径返回：现有证据与真正缺口

保留 v6 已核对的直接事实：gap=6、目标 R12 时，有 EX2 的目标消费窗口为 33 周期，预装值消费与 NOP 为 32；EX2 目的改为奇数、偶数或 RZ 后局部 +1 仍存在。EX2 换 NOP，或目标改为 R15，+1 消失；相邻 gap=5/7 的目标相对 NOP 差值为 0。实际消费者均取得正确新值。

这说明指定返回条件与目标消费有交互；没有显示无消费者的生产者窗口同样加 1。因而不能把它写成“每次跨路径返回加 1”“偶数寄存器加 1”，也不能给不同 opcode 各设一个 RF 系数。

剩余缺口是条件到限制的因果关系：外层时钟没有给出结果实际到达与观察者实际取值的时刻，无法判断局部交互由哪一段返回／供给／取值时序触发。要将局部观察推广为统一规则，需要能区分这些解释的对照或直接的内部时间证据；继续增加布局和 N 的同类零差样本补不上这个缺口。只有明确了可辨别的假设和相反预期，才值得设计下一项测试。

当前能交付给上层评估的规则

适用条件可直接使用的结论禁止的外推
本轮固定帧、高密度单 warp 标量结果流按实际控制字段求得推进窗口；被测布局与 N 的额外可观测推进差为 0。任意指令流的总耗时公式、峰值 RF 带宽、零物理写服务时间。
本轮两位置及已有 v6.1 观察条件推进与可用性分别检查；gap=4 不具备跨条件稳定性，本轮 gap=5/6 均通过。把 gap=5 当统一物理延迟；仅凭总窗口认定全部结果已可用。
v6 特定目标／EX2／gap 条件保存精确条件及局部窗口差，作为必须解释的反例。将局部 +1 拼成经验惩罚；把未识别的路径限制默认设为 0。
超出本轮范围的宽结果、多结果同时返回及其他供给条件保留未确定状态，不能声称本轮覆盖。用不同指令的整段耗时差反推统一每字写成本。

对 work 完成状态的回答：本轮的目的布局与连续结果数量目标，在明确的测试范围内已完成；“所有不同路径返回条件下的统一限制及量化规则”仍未完成。可交付的是上表中的有证据规则及其适用范围，而不是一个用经验常数补齐的完整模型。

308 周期不能作为 RF 写服务时间。计时区间机器码不变，同址预热后变为 146 / 147 / 152 周期。

在本轮预热条件下，推进窗口逐点等于 SASS 显式控制间隔之和；但相同 146 周期窗口和相同名义 gap=4，代码平移后目标值从全部读对变成全部读错。推进与可用性必须分别约束。

原样复现组完整复现 v6；同址预热 8 遍与 32 遍的所有配对结果一致。改变预热和代码位置确实能改变原窗口，因此旧 308 周期包含执行历史或位置敏感的影响。我的 v6 测试没有建立每次正式采样前的同址预热对照，这一设计缺口已被硬件结果证实会影响测量。
