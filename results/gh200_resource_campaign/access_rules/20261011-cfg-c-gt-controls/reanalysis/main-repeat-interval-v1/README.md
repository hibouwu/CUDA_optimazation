每次时长区间为[MAIN_pre−FIRST_post, MAIN_post−FIRST_pre]。令a=max各次下界、b=min各次上界，则R=max(0,a−b)是所有允许取值中的最小跨次时长跨度：两个极端窗口给出下界，逐个把b投影到对应闭区间可达到该下界；脚本保存极端记录ID和达到值，逐条核对。

额外GT坐标误差设为0时，432个系列均无共同精确时长。R的最小/中位/最大为192/576/1344；原生clock64窗口差的跨次范围为24/384.5/1347 cycles（只是含标记代码的记录差，不是裸MMA价格）。因此在该条件下，已保存的读取宽度不能单独解释所有跨次差异。不能由此区分真正执行变化、计数率变化或未计入的GT误差。

若每个GT读允许独立±e误差，时长区间两端各扩2e，闭合最坏交集缺口需要至少e=R/4。该必要预算最小/中位/最大为48/144/336；脚本验证此预算允许共同值，而小1/4仍不允许。它只是放松为独立端点盒后的每系列可行性阈值，不是测得的GT精度、建议容差或所有系列共享物理时钟轨迹的充分证书。
