完整 6372 系列、两批四臂、每臂 64 次的合成见证中，两臂每个坐标的完整排序边际相同，12744 项条件等价均通过；共同尾波动改为分散尾波动后，同调用 consumer FINAL 包络的中位数仍相差任意符号幅度 H=1000。它不是 1000 ns 的实测变化，也不是实际 GPU 执行。两种联合总体都可在调用间 IID，因此仅证明 IID 不能补足缺失的联合关系。
