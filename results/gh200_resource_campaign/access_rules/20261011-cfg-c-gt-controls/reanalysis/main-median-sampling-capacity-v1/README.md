# 中位数比较的采样能力

若未来采用中位数及其不确定度，原每臂十次进程重复不能直接换成全坐标有效性结论。在本文的**未插值次序统计量区间 + Bonferroni**构造下，示例性 95% 同时覆盖要求至少每臂 16 次才能为一批全部 432 个 L 坐标给出有限区间。该数不是通用最小样本量，不是新采样批准或新观测门槛，也不保证区间足够窄。

## 方法与假设

对一个坐标、一臂的 n 个进程读数排序为 `X_(1)…X_(n)`。若这些进程独立同分布，则总体中位数落在 `[X_(k), X_(n-k+1)]` 之外的概率至多为

\[
 q(n,k)=2\sum_{j=0}^{k-1}\binom{n}{j}/2^n.
\]

连续分布的界可取等号；中位点有离散质量时覆盖可更保守，不给量化时间戳加随机扰动或插值。若同时覆盖 m 个臂中位数，失败概率的并集界为 `m*q(n,k)`。此并集界不要求 CTA 坐标之间、两臂之间独立，但每个坐标/臂内部的进程重复仍须满足采样假设。

两臂中位数区间分别为 `[a_lo,a_hi]`、`[b_lo,b_hi]` 时，中位数之差的区间为 `[b_lo-a_hi,b_hi-a_lo]`。这个量不同于“配对差的中位数”，也不自动等于 observer 的因果影响。

二项分布与次序统计量关系参见 [NIST：Median Confidence Limits](https://itl.nist.gov/div898/software/dataplot/refman1/auxillar/mediancl.htm)；本分析只使用未插值整数秩，不采用该页面的插值近似。同时覆盖的并集界见 [NIST：Bonferroni's method](https://www.itl.nist.gov/div898/handbook/prc/section4/prc463.htm)。

740161 是先后执行的 off/on 与 off/off 两批，新进程不代表卡状态独立或总体恒定。本文没有证明上述采样假设对旧数据成立。因此旧数据上的数值区间只是条件方法演示，没有获得正式置信覆盖资格。

## 有限区间所需重复数

表内只算**一个计量域**；ns 与 cycles 各自查看，不宣称两域共同覆盖。两批指 off/on、off/off，各有两臂。最宽的有限次序统计量区间取样本最小和最大，即 k=1。

| 同时覆盖的范围 | 臂中位数个数 m | 此构造下有限区间的最小每臂 n |
|---|---:|---:|
| 一个坐标、一批两臂 | 2 | 7 |
| 一个坐标、两批四臂 | 4 | 8 |
| 432 个 L 坐标、一批两臂 | 864 | 16 |
| 432 个 L 坐标、两批四臂 | 1728 | 17 |
| 原 6372 个控制系列、一批两臂 | 12744 | 19 |
| 原 6372 个控制系列、两批四臂 | 25488 | 20 |

例如一批全部 L 在 n=15 时，即使用最宽有限区间，并集覆盖下界也只有 94.7265625%；n=16 时升至 97.36328125%。这些是该构造的保证，不是实际覆盖概率的估计；利用额外分布或依赖结构的方法可能不同。432 个同进程坐标不能当作每臂新增 432 次进程重复。原 6372 系列的两行只计算秩容量，未对全部系列重做数值区间。

## 旧十次记录的条件演示

只覆盖**单个坐标的一批两臂**时，n=10 可取每臂第二至第九次序统计量，中位数之差的并集覆盖下界为 95.703125%。将它分别应用到 432 个坐标，不再拥有 95% 全坐标同时覆盖保证。

|---|---:|---:|---:|---:|
| off/on，ns | 432/432 | 800 | 1280 | 364 |
| off/off，ns | 432/432 | 1120 | 1792 | 406 |
| off/on，cycles | 329/432 | 373.5 | 1782 | 417 |

包含零不能证明等价；若要证明差异在预定容差内，应要求有效的不确定区间整体落入容差，而不是只要求包含零。本文没有设等价容差或输出通过数。时间戳准确度、observer 扰动、关键 CTA 的逐次排序均需单独证据，不能由此表推导。
