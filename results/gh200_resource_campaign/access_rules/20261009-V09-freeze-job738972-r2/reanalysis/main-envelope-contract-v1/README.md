# 固定V09 r2包络主线重算

从原批准清单绑定的30条件重新提取静态输入并构造精确有理数分段包络，随后运行不导入构造器/公共模型的顺序分支检查器。`envelope.json.gz`、`verification.json`和`current-clock-binding.json`三个完整JSON与A交付逐字段相同；压缩字节不作为等价标准。

复验覆盖14项输入SHA、3516个CTA实例、50个区间、141个CTA分组区间、1113条分支不等式、45个最终包络分段；三个损坏证书均被拒绝。360次归档数值入口核对最大相对差1.9984014443252818e-15。当前求根函数AST与冻结版相同，时钟映射仅归一化duration_term导入限定名。

这只证明固定r2十进制参数的有理数公式满足连续、正值、随频率非增和低频发散契约；源时钟映射非减，加上减去f的项使联立残差严格递减，正根唯一。不是硬件频率测量，也不证明提取器或全部IEEE舍入路径。不能用另一正根修补该版时间误差；后续供给/输出或历史状态改变需要重新验证契约。

保留29 predicted、1 unsupported（cfg_c G2），不改变开发失败、观察门槛或独立留出要求。无GPU运行、价格修改或预测资格升级。

复验：在本目录运行`python verify.py`和`python binding.py`。完整重建需将本目录三脚本复制到新的空输出目录，以`python analyze.py --frozen <原r2目录> --output <新目录>`生成证书，再运行两个复验脚本。
