# 同二进制累计观察反馈诊断

复用八目标correctness已验证的新binary。固定16组，每组两stage×ALL15/ONLY2/ONLY16共六个新进程，合计96目标；组内均匀独立随机排列，seed20261011，实际顺序在manifest中。每目标16次同buffer/同stage binary的OFF前序。OFF不加入性能臂，已有八目标检查不混入本批。

每stage每组先由同一次ALL调用取Q2与Q16，定义L16=Q16_ALL−Q16_ONLY16，L2=Q2_ALL−Q2_ONLY2，F=L16−L2。两stage共六个预列量分别报告中位数；F必须在组内先计算，不能用两个中位数相减。原始D和完整progress字段随记录保留，不把单组sum或D−sum解释为完整Q/R。

L16比较此前14次与0次观测bundle，L2控制此前没有选中观测的group2。bundle含H/B、累加校验、选择和汇合，F不等于纯collector算术成本；有限stage对producer/consumer的反馈不预设方向。含0的区间不能判对照等价或无反馈，也不能从新协议校正旧38条collector的测量。

在IID且同分布的block向量假设下，六量用16样本第3～14秩构造至少95%同时区间；单量两尾界137/32768，六量并集界411/16384。随机顺序不证明GPU样本IID，区间只作条件解释，16组不保证精度。保留每组结果，不按显著性加样。若第16组差在各组呈系统方向而第2组背景差更小，可定位到观察历史相关响应；即便F含0也不恢复未插桩Q。

只在指定ef/a058排他分配运行一条计时流，按实际4GPU/288CPU记资源。任一格式/数值/执行位或CTA0 SM映射检查失败即停止并保留；不替换、不追加、不评分不完整批次。此为机制诊断，不拟合公共模型，不授观察、服务、关键CTA、新留出或跨卡资格。最终cfg_a/b/c目标保持。

3项CPU检查含缺项/归属/None拒绝、相干联合差的中位数不可减反例及完整65536符号枚举的秩尾界。
