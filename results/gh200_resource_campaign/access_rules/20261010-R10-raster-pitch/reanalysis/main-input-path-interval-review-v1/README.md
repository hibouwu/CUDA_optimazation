只读快照B尚未提交的analyze_r10_input_path_interval.py，SHA固定在verification中，未接入公共模型。独立verify_signs.py以普通Fraction算术检查300个比较、2520个严格内部点及6个相等时刻heap排序；20个非恒等相等分支均正确缩为单点。该有限检查验证比较和队列排序基础机制，不证明全部仿射表达式或完整事件图。

源码检查确认：事件时间通过Affine比较记录约束；零斜率比较不收窄价格域；相等时刻仍由事件serial排序。AST变换把float常量转为其原二进制值的精确有理数，在全部首MAIN后返回；它证明的是这套有理数解释，不能自动证明所有IEEE舍入执行。

交付验收仍需：核对最终源码是否匹配或重新审查；所有分段开区间及每个端点单独覆盖；达到maximum_cells时保留剩余区间，不能把局部完成写成全覆盖；用原浮点完整图核对对应端点；单条件反例只在该条件已属固定范围且观测边界明确时用于排除共同价格，不将单条件证明当作全cfg预测通过。
