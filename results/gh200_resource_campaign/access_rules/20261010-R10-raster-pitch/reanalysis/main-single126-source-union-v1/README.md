# single126静态源并集独立核对

针对原固定single126 B0/B32上下文，由现有cfg_b描述符程序生成逻辑请求，再独立逐个FP16元素计算两字节的全局地址所属128B单元。两布局各512个不同描述符、3276800个有效元素，合计6553600，逐描述符与source_granules结果相同。独立枚举没有复用其按行区间计算公式。

| 布局 | 每K组A单元 | B单元 | 总单元 | 每单元只服务一次时的模型费用 |
|---|---:|---:|---:|---:|
| B0 | 2304 | 896 | 3200 | 183.626002937ns |
| B32 | 2304 | 944 | 3248 | 186.380392981ns |

每布局16个K组计数相同，120个组对的地址单元交集均空，共240项不重叠检查。A/B地址空间分别标记，未因相同相对地址错误合并。上述单元是名义地址覆盖，不是物理L2/HBM流量。

费用使用既有service_ns/128价格，未重新拟合。它只有在同组所有共享需求均在相关源单元订阅到期前到达时，才可作为该组一次性源工作界；本文件没有证明订阅生命周期或完整价格区间。若订阅过期，重复generation仍需支付，不能由静态并集直接省略。不同K组不共享单元，只简化跨组计账，不能消除组内时序条件。

复验`python verify.py`，输入/源码SHA保留在report。无新增GPU、数值样本或资格。
