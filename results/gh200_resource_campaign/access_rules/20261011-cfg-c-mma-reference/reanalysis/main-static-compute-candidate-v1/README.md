# cfg_c同卡静态计算窗口候选

候选入口cfg_c_native_compute.py只接收静态setup和独立指令参考。固定cfg_c/tile256×128×64/cluster1×2/S4、相同设备，K为正64倍数；其它组织和跨卡直接拒绝。输出实验性compute-only状态，所有预测/观察资格false，不改变全cfg_a/b/c目标或原受支持集合。

价格仅取740095预定1024组的三次cycle中位1049379，参考工作4294967296 FLOP。预测C=(2×256×128×K)×1049379/4294967296。K4096得到1049379/16=65586.1875cycle；没有使用GEMM目标cycle、残差、截距、ns换算、源或输出价格。

在已揭示740092的20同卡进程/4320共同窗口上，绝对相对误差中位0.541092%、最大2.911510%。这是独立指令测量支撑的开发候选，不是新冻结留出：选择发生在目标已揭示之后，SM124重复操作数微基准对其它SM/真实GEMM的适用性仍是假设，原局部观察失败未解除。

检查旧738496/738865的15个cfg_c条件时发现实际卡均为GPU-43269fbc，与新ef参考不同。全部保留明确拒绝原因，未换UUID、套价或把历史跨K诊断当同卡验证。后续可在新本地冻结中检验K/行距迁移，并独立建立跨卡边界；当前不请求完整V10。

三项语义测试通过：精确静态工作比例、设备/组织/K拒绝、参考形状/批次/非法cycle拒绝。reference.json绑定独立测量来源，windows.json.gz保留全部开发误差，report.json保留15个拒绝。没有新GPU或整体性能结论。
