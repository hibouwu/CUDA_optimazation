# producer-tail与首轮MAIN的因果边界

检查已有cfg_c K64、S4完整rank依赖图，T1/T2各四角色×两producer尾部共16个可达性查询。T2首轮MAIN通向本cluster两个producer_tail，8条最短路径完整保存；T1首轮MAIN与producer_tail无任一方向路径，它们都在释放之后，不能由该图推出先后。此结论只覆盖本物理cluster，不提供全卡共享资源顺序。

再读取740091十个on记录，完整264首轮角色全部保留。每次最早tail戳均来自T1 CTA；只有14..48个首轮MAIN读数严格早于所有tail戳，其余216..250个在最早tail戳时或之后。T2的168角色均先于本cluster最早tail，观测间隔42.688..46.624us；这不能排除其它cluster较早的采样执行。

因此撤回“所有tail记录都在首轮L之后，不能影响首轮”的笼统推断。跨CTA globaltimer顺序仅作为原读数报告，未假设已证明的物理包围精度；源码偏序与读数顺序分别保存。当前结果不证明tail指令开销、共享资源干扰或物理时钟原因，也不改变原扰动失败。

若继续最小对照，先用相同binary、相同16次前序、相同交替配对流程做两臂均off的基线，检验未增加tail采样时是否已出现同量级局部配对差。它能检查配对流程的背景变化，不能单独证明开启tail无扰动；不得用其结果减去原失败或放宽阈值。本轮未创建新冻结或执行GPU。
