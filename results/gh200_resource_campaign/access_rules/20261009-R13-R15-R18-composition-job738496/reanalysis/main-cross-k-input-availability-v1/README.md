其余目标有先前参考可用，不代表原同trial参考可用，也不代表获得静态输入自由预测。本次未选择替代参考、未删除目标、未重算分数。原12960窗口条件误差仍完整保留；它只能描述离线转移关系。K伴随A行距/分配变化和不同自适应历史，不能作为纯K因果实验。
