# guarded共同可变时钟：直接raw反例

主集成复验A的138份证书及1584次原括号交集，不调用求解器；另外从740071冻结guarded raw独立提取528个三元戳，与A输入逐项一致，并将其无上限、零额外端点容差负闭环缩成以下两个窗口。

两个窗口的起止globaltimer读数完全相同，差为18880ns。每个周期增量区间仅在同一SM内部计算：下界=end.before−begin.after，上界=end.after−begin.before。

| SM | 起点 | 终点 | 周期增量区间 |
|---|---|---|---:|
| 57 | WG1 MAIN | WG2 MAIN | [33043,33198] |
| 68 | WG2 FIRST | WG2 MAIN | [33573,33720] |

若timer硬件取样确在CLOCK括号内，且不额外平移timer端点，则全卡共同F在相同起止时刻必须有相同增量；SM计数原点相减后消失。两个区间相隔375cycle，没有交集。该375恰为保存的四边负闭环权重之负值，无需常数率假设、1.98上限或跨SM原始clock相减。

这是已有全部数据矛盾的一项事后可读见证，不是挑选新验收子集。完整528戳模型的最小可行整数额外单端点容差：有旧1.98上限为187ns，无上限为177ns；分别由相邻整数的不可行/可行证书支持。无上限下确界位于[176,177]，可取性未证；这些容差与128ns总窗口预算不同。

每SM独立可变曲线在零额外容差下的132个条件见证也验证通过。不能据此断言SM物理频率不同、timer误差为177ns或硬件包围已成立。目标读数构造的曲线不是可用预测参数；扰动/空间资格仍未取得，observation_qualified=false。
