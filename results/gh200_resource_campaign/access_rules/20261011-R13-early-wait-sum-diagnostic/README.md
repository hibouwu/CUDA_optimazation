# R13 等待内外的分组诊断

固定 cfg_b 2816×1536×4096、CTA0/thread256、第二输出 local2..16；复用 job740240 的 stage4/6 binary，各组四臂为 s4/off、s4/on、s6/off、s6/on。每个目标在新进程内先完成16次同buffer、同stage binary的off前序。stage之间的前序kernel不同，不称相同历史状态。

共16组、64个目标，每组独立随机排列四臂，种子20261011；完整顺序在manifest中。只用指定ef卡/a058排他分配的一条计时流，实际占4GPU。任一数值/trace检查失败或目标CTA的SM改变就停止并保留，不替换、不加样、不评分不完整批次。四目标smoke只证明采集可用，不并入本批。

令 D=C16−C1，Q为同调用15组累计full try/wait cycles，R=D−Q。每组预列八个量：开启观察的stage差 ΔD、ΔQ、ΔR、ΔQ−ΔR，关闭观察的stage差 ΔD_off，stage差的开关交互 ΔD−ΔD_off，以及stage4、stage6各自的on−off D。逐组必须满足 ΔD=ΔQ+ΔR 和交互=s4(on−off)−s6(on−off)。关闭时的Q/R未观测。

保存全部逐组数据、各量中位数和精确sum/count。分别取的中位数不能相加，交互的中位数也不能用两个stage差中位数相减替代。若16组可视为同分布独立样本，八个中位数用第3～14次序量形成同时区间；单量两尾界137/32768，Bonferroni并集界137/4096<0.05。随机顺序并不能证明这个IID假设，报告必须标为条件区间；16组不保证精度。

本批回答插桩后stage差发生在等待内还是外，以及总进度窗口如何随观察开关变化。区间含0不能称等价；D没有明显变化也不能排除Q/R重新分配。R包含collector算术/调度，Q包含前面collector改变到达时间的反馈，均不等于未插桩服务价格。不换算ns，不拟合公共模型，不授局部观察、关键CTA、新留出或跨卡资格。全cfg_a/b/c最终目标不变。

先看开启观察的stage差能否重复，再看同组ΔQ、ΔR及ΔQ−ΔR的方向。若等待差反复存在，下一机制应针对full等待及累计观察反馈；若等待外差占主要方向，则先查循环/发射/释放与collector路径；若不能区分，保留未识别。这个选择只针对当前插桩路径，不把总窗开关检查当Q有效性的证明。
