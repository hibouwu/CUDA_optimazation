# 源/目的延迟重标记：继承已有截止分支的失败

整box模型中，将共同读延迟L全部移到每个目的请求，与已有service_end截止分支完全等价。
两者都在server_end严格关闭订阅，每个需求都在server_end+L进入同一目的FIFO。
源代次、投递、消费、释放、输出和后续请求按归纳保持；内部source_ready标签不同。
